## Create PE File Validation

### Nguyên lý

Mục đích:  Kiểm tra tính hợp lệ và cấu trúc định dạng của tệp thực thi di động Windows (Portable Executable - PE, bao gồm `.exe`, `.dll`, `.sys`, `.ocx`, `.scr`).

Nguyên lý kiểm định dựa trên 2 lớp trong cấu trúc PE File:
- **DOS Header**: chứa hai kí tự `MZ` (hay `0x5A4D`) tại 2 bytes đầu tiên của file
- **PE Header**: Đọc con trỏ địa chỉ `e_lfanew` tại offset `0x3C` (kích thước 4 bytes/`DWORD`) để thực hiện nhảy đến vị trí bắt đầu của PE Header và xác thực signature `PE\0\0` (`0x00004550`)

![alt text](https://github.com/UITxWoodyNguyen/myblog/blob/main/_posts/research/PE-Analyzer-Week-1/image.png?raw=true)

### Nạp hằng số và xây dựng CTDL cho kết quả xác thực trả về

Từ nguyên lý cơ bản, xây dựng các hằng số cần dùng cho việc xác thực:
```python
MZ_SIGNATURE = 0x5A4D        # "MZ" (Mark Zbikowski) dạng Little-Endian: [0x4D, 0x5A]
PE_SIGNATURE = 0x00004550    # "PE\0\0" dạng Little-Endian: [0x50, 0x45, 0x00, 0x00]
E_LFANEW_OFFSET = 0x3C       # Vị trí lưu con trỏ trỏ tới PE Header trong DOS Header (60 trong hệ thập phân)
E_LFANEW_SIZE = 4            # Kích thước con trỏ e_lfanew (DWORD = 4 bytes)
```

Xây dựng CTDL cho kết quả xác thực được trả về gồm 3 thuộc tính:
- `path: string`: lưu đường dẫn của file cần kiểm tra
- `isValid_PE: bool`: Trạng thái của file (có hợp lệ hay không)
- `reason: string`: Mô tả trạng thái chi tiết

```python
@dataclass
class PECheckResult:
    path: str           # Đường dẫn file được kiểm tra
    isValid_PE: bool    # True nếu file là PE hợp lệ, ngược lại False
    reason: str         # Thông điệp trạng thái chi tiết (lý do hợp lệ hoặc lỗi)
```

### Quy trình xử lý chi tiết

Xây dựng hàm `PE_checker(file_path, full_check)` trả về một `PECheckResult` với tham số đầu vào bao gồm:
- `file_path`: Đường dẫn file cần kiểm tra
- `full_check`: `True` (Kiểm tra cả 2 lớp DOS Header và PE Header), `False` (Chỉ kiểm tra DOS Header)

## Create Hash Module

### Nguyên lý

Mục đích: Module này thực hiện tính toán mã băm an toàn (MD5 và SHA-256) cùng dung lượng kích thước tệp tin phục vụ nhận diện mẫu mã độc, truy vấn cơ sở dữ liệu danh tiếng (Threat Intelligence) và xác thực tính toàn vẹn dữ liệu.

Tối ưu hoá bộ nhớ:
- Module sử dụng kĩ thuật **Streaming Chunk-by-chunk** (đọc từng khối dữ liệu nhị phân với size mặc định 64 KB thay vì nạp toàn bộ file vào bộ nhớ RAM).
- Cho phép băm an toàn các tệp tin có dung lượng lớn (từ vài trăm MB đến hàng chục GB) trên các máy chủ hoặc môi trường sandbox có bộ nhớ giới hạn.

### Xây dựng CTDL

Thực hiện nạp hằng số mặc định `DEFAULT_CHUNK_SIZE` - kích thước chunk mặc định cho mỗi lần xử lý:
```python
DEFAULT_CHUNK_SIZE = 64 * 1024  # 65,536 Bytes = 64 KB 
```

Xây dựng CTDL cho Kết quả băm trả về - `HashResult` với các thuộc tính:
- `path: string`: Đường dẫn của file được hashing
- `size_bytes: int`: Dung lượng file tính theo bytes
- `md5_hash: string`: Chuỗi MD5 Hexadecimal (32 kí tự)
- `sha256_hash: string`: Chuỗi sha256 Hexadecimal (64 ký tự)
- Tính năng `__getitem(self, key)`: Tác dụng giúp truy cập linh hoạt theo syntax object hoặc theo key dictionary

```python
@dataclass
class HashResult:
    path: str           # Đường dẫn file đã được băm
    size_bytes: int     # Dung lượng file tính theo byte
    md5_hash: str       # Chuỗi MD5 Hexadecimal (32 ký tự)
    sha256_hash: str    # Chuỗi SHA-256 Hexadecimal (64 ký tự)

    def __getitem__(self, key: str):
        """Hỗ trợ truy xuất kiểu Dictionary để tăng tính tương thích."""
```

Xây dựng lớp ngoại lệ cơ sở - `HashError`:
```python
class HashError(Exception):
    """Ngoại lệ cơ sở được ném ra khi có lỗi I/O hoặc lỗi truy cập tệp."""
    pass
```

### Quy trình xử lý chi tiết

Xây dựng hàm `calculate_hash(file_path, chunk_size = 64KB)` trả về một `HashResult` với danh sách tham số:
- `file_path`: Đường dẫn đến đệp tin cần hashing
- `chunk_size`: Kích thước mỗi chunk cần đọc (Mặc định 64KB)

Quy trình:
- Step 1: Kiểm tra điều kiện của `chunk_size`. Nếu dương thì thực hiện, ngược lại trả về `ValueError`.
- Step 2: Khởi tạo 2 instances `hashlib.md5()` và `hashlib.sha256()`
- Step 3: Mở file ở chế độ Read Binary (`rb`) và đọc từng `chunk_size`. Đồng thời cập nhật song song kết quả của 2 thuật toán Hashing với từng block nạp vào bộ nhớ.
- Step 4: Gọi `hexdigest()` để lấy mã băm dạng HexaDecimal và packing vào `HashResult`

## Model Checking with `pytest`

Check code:
```python
import unittest
import hashlib
import sys
import pytest
from pathlib import Path

'''
This file is used to test `pe_checker.py` and `hasher.py` modules.
Compile: "python3 test_hasher.py -v"
'''

PROJECT_ROOT = Path(__file__).parent.parent
if str(PROJECT_ROOT) not in sys.path:
    sys.path.append(str(PROJECT_ROOT))

from src.core.hasher import calculate_hash, HashError
from src.core.pe_parser import PE_checker

def reference_hash(path: Path) -> tuple[str, str]:
    '''
    Calculate MD5 and SHA256 ground-truth independence hash values for a given file.
    '''

    data = path.read_bytes()
    md5_hash = hashlib.md5(data).hexdigest()
    sha256_hash = hashlib.sha256(data).hexdigest()
    return md5_hash, sha256_hash

# Test 01: Checking valid PE file 
def isValid_x64_exe(pe_x64_exe):
    result = PE_checker(pe_x64_exe)
    assert result.isValid_PE is True, f"Expected True, got {result.isValid_PE}"

def isValid_x86_exe(pe_x86_exe):
    result = PE_checker(pe_x86_exe)
    assert result.isValid_PE is True, f"Expected True, got {result.isValid_PE}"

def header_quick_check(pe_x64_exe):
    result = PE_checker(pe_x64_exe, full_check = False)
    assert result.isValid_PE is True

# Test 02: Detection and handling of invalid PE file
def test_truncated_1byte_rejected (truncated_1byte):
    result = PE_checker(truncated_1byte)
    assert result.isValid_PE is False

def test_truncated_before_header_rejected (truncated_before_header):
    result = PE_checker(truncated_before_header)
    assert result.isValid_PE is False

def test_corrupted_reject (corrupted_pe):
    result = PE_checker(corrupted_pe)
    assert result.isValid_PE is False

def fake_exe_rejected (fake_exe):
    result = PE_checker(fake_exe)
    assert result.isValid_PE is False

def test_fake_signature_rejected (fake_MZ):
    result = PE_checker(fake_MZ, full_check = True)
    assert result.isValid_PE is False, f"Expected False, got {result.isValid_PE}"

    result = PE_checker(fake_MZ, full_check = False)
    assert result.isValid_PE is True, f"Expected True, got {result.isValid_PE}"

def file_not_found(non_existent_file):
    result = PE_checker(non_existent_file)
    assert result.isValid_PE is False

# Test 03: Hashing module to calculate MD5 and SHA256 hash values
@pytest.mark.parametrize("fixture_name", ["pe_x64_exe", "pe_x86_exe"])
def test_hash_matches_ref (fixture_name, request):
    path = request.getfixturevalue(fixture_name)
    result = calculate_hash(path)
    expected_md5, expected_sha256 = reference_hash(path)

    assert result['md5'] == expected_md5, f"MD5 mismatch: expected {expected_md5}, got {result['md5']}"
    assert result['sha256'] == expected_sha256, f"SHA256 mismatch: expected {expected_sha256}, got {result['sha256']}"
    assert result['file_size'] == path.stat().st_size, f"File size mismatch: expected {path.stat().st_size}, got {result['file_size']}"


@pytest.mark.parametrize("chunk_size", [1, 64, 4096, 65536])
def test_hash_chunk_independence(pe_x64_exe, chunk_size):
    result = calculate_hash(pe_x64_exe, chunk_size=chunk_size)
    expected_md5, expected_sha256 = reference_hash(pe_x64_exe)

    assert result['md5'] == expected_md5, f"MD5 mismatch: expected {expected_md5}, got {result['md5']}"
    assert result['sha256'] == expected_sha256, f"SHA256 mismatch: expected {expected_sha256}, got {result['sha256']}"

def test_hash_nonexistent_file(non_existent_file):
    with pytest.raises(HashError):
        calculate_hash(non_existent_file)

# Test 04: Merge process: Check PE -> Hashing -> Compare with reference hash
def full_process_check(pe_x64_exe):
    pe_result = PE_checker(pe_x64_exe)
    assert pe_result.isValid_PE is True

    hash_result = calculate_hash(pe_x64_exe)
    assert len(hash_result['md5']) == 32
    assert len(hash_result['sha256']) == 64
```
